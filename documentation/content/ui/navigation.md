# 画面遷移

## ルート

| URL          | 画面                           | 動作                                       |
| ------------ | ------------------------------ | ------------------------------------------ |
| `/`          | ルート                         | `/tasks`へリダイレクトする                 |
| `/tasks`     | [タスク一覧](./task-list.md)   | 一覧、登録、編集、削除、チャートを提供する |
| `/tasks/:id` | [タスク詳細](./task-detail.md) | URLの`id`に対応するタスクを表示する        |
| その他       | 404                            | 要求されたURLと一覧へ戻るリンクを表示する  |

## 遷移規則

- 一覧のタスク名から、そのタスクの`/tasks/:id`へ遷移する。
- 詳細画面の「タスク一覧」から`/tasks`へ戻る。
- 404画面の「タスク一覧に戻る」から`/`を経由して`/tasks`へ戻る。
- ブラウザー履歴による戻る・進むを利用できること。

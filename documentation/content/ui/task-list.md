# タスク一覧

## 初期表示

画面表示時に[一覧取得API](../api/endpoints.md#タスク一覧取得)を実行します。取得中は読み込み表示、成功時はタスク、失敗時はエラーを表示します。更新ボタンで同じ取得処理を再実行できます。

## 画面構成

1. ページ見出しと更新ボタン
2. タスクリスト、ガントチャート、バーンダウンチャートの表示切り替え
3. [サマリー](../rules/presentation.md#サマリー)
4. エラー表示
5. 選択中の表示領域

チャートの内容は[表示・集計ルール](../rules/presentation.md)に従います。

## 新規登録

登録フォームはタスク名、担当者、開始日、期限、優先度を受け付けます。開始日と期限の初期値は当日、優先度の初期値は`medium`です。入力値は[タスクモデルの制約](../domain/todo.md#入力制約)に従います。

登録時の動作は次のとおりです。

1. タスク名の前後空白を除く。
2. 日付の不変条件を確認する。
3. 送信中は登録ボタンを無効化する。
4. [登録API](../api/endpoints.md#タスク登録)の成功後、新しいタスクを一覧の先頭へ追加する。
5. タスク名を空にし、他の入力値は保持する。

## 一覧操作

- 検索欄と状態選択は[検索と絞り込み](../rules/presentation.md#検索と絞り込み)に従う。
- タスク名を選ぶと[タスク詳細](./task-detail.md)へ遷移する。
- 完了ボタンは現在と反対の完了状態を[更新API](../api/endpoints.md#タスク更新)へ送る。
- 編集ボタンはタスク名をインライン編集へ切り替える。保存成功後に表示を更新し、キャンセル時は変更を破棄する。
- 削除ボタンは確認ダイアログを表示する。承認後に[削除API](../api/endpoints.md#タスク削除)を実行し、成功したタスクを一覧から除く。

## 表示状態

| 状態       | 表示                                 |
| ---------- | ------------------------------------ |
| 読み込み中 | 進行表示と「タスクを取得しています」 |
| 0件        | 空状態と条件変更または登録を促す説明 |
| 通信失敗   | APIのエラーメッセージを含むバナー    |
| 完了タスク | 完了アイコンと視覚的な完了表現       |

エラーバナーは閉じる操作を提供します。後続操作の開始時に以前のエラーを消去します。

# タスク詳細

## 取得

URLの`id`を使って[単一タスク取得API](../api/endpoints.md#単一タスク取得)を実行します。画面表示ごとに対象タスクを取得します。

## 表示項目

- 完了または未完了の状態
- タスク名
- 担当者
- 開始日
- 期限

各項目の定義は[タスクモデル](../domain/todo.md)を参照してください。

## 表示状態

| 状態       | 表示                               |
| ---------- | ---------------------------------- |
| 読み込み中 | 進行表示と読み込み中の説明         |
| 取得成功   | タスクの詳細カード                 |
| 取得失敗   | APIのエラーメッセージ              |
| 対象なし   | タスクが見つからないことを示す説明 |

常にタスク一覧へ戻るリンクを表示します。

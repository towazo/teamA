# タスクモデル

## Todo

| 属性          | 型                  | 必須 | 説明                                            |
| ------------- | ------------------- | ---- | ----------------------------------------------- |
| `id`          | string              | 常時 | `TD-`と連番で構成する識別子。生成後は変更しない |
| `title`       | string              | 常時 | タスク名                                        |
| `assignee`    | string              | 常時 | 担当者名                                        |
| `isCompleted` | boolean             | 常時 | 完了状態                                        |
| `startDate`   | date string         | 常時 | 開始日                                          |
| `dueDate`     | date string         | 常時 | 期限                                            |
| `completedAt` | date string \| null | 常時 | 完了日。未完了時は`null`                        |
| `priority`    | Priority            | 常時 | 優先度                                          |

日付文字列は`YYYY-MM-DD`形式とし、時刻を含みません。

## Priority

| 値       | 表示名 | 意味                         |
| -------- | ------ | ---------------------------- |
| `high`   | 高     | 優先して対応する             |
| `medium` | 中     | 通常の優先度で対応する       |
| `low`    | 低     | 他のタスクより後に対応できる |

## 入力制約

| 属性        | 制約                                                   |
| ----------- | ------------------------------------------------------ |
| `title`     | 前後空白を除いた1文字以上80文字以下                    |
| `assignee`  | 前後空白を除いた1文字以上30文字以下                    |
| `startDate` | 有効な日付形式。登録時に省略した場合は日本標準時の当日 |
| `dueDate`   | 有効な日付形式                                         |
| `priority`  | Priorityで定義した値のいずれか                         |

## 不変条件

- `startDate`は`dueDate`以前であること。
- `isCompleted`が`false`のとき、`completedAt`は`null`であること。
- `isCompleted`が`true`のとき、`completedAt`は完了状態へ変更した日本標準時の日付であること。

## 状態遷移

新規タスクは未完了で生成します。完了へ変更すると`completedAt`に当日を設定し、未完了へ戻すと`null`にします。完了状態を変更しない更新では、既存の`completedAt`を保持します。

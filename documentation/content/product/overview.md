# プロダクト概要

## 目的

利用者がタスクの登録、確認、更新、削除を一つのワークスペースで行い、期限と進捗を一覧および時系列で把握できるようにします。

## 利用者

認証を必要としない単一ワークスペースの利用者を対象とします。すべての利用者は同じタスク集合を操作します。

## 機能要件

| ID    | 要件                                                                   |
| ----- | ---------------------------------------------------------------------- |
| FR-01 | タスクを一覧表示できること                                             |
| FR-02 | キーワードと完了状態で一覧を絞り込めること                             |
| FR-03 | タスクを登録できること                                                 |
| FR-04 | タスク名と完了状態を更新できること                                     |
| FR-05 | 確認操作を経てタスクを削除できること                                   |
| FR-06 | タスクの詳細を個別に表示できること                                     |
| FR-07 | 全タスクの予定をガントチャートで表示できること                         |
| FR-08 | 全タスクの進捗をバーンダウンチャートで表示できること                   |
| FR-09 | 進捗、残数、期限超過数、次の期限を要約表示できること                   |
| FR-10 | 読み込み中、空状態、通信エラー、存在しない画面を識別して表示できること |

## 対象外

- ユーザー認証と権限管理
- ワークスペースの分離と共有
- 添付ファイル、コメント、通知
- サーバー再起動後も残る永続ストレージ

データ構造は[タスクモデル](../domain/todo.md)、操作方法は[画面仕様](../ui/task-list.md)を参照してください。

# 実行環境

## システム構成

| 要素           | 技術                   | 役割                     |
| -------------- | ---------------------- | ------------------------ |
| フロントエンド | Vue、Vue Router、Vite+ | 画面表示とAPI呼び出し    |
| バックエンド   | Hono、Zod、Vite+       | REST APIと入力検証       |
| 仕様書         | Ox Content、Vite+      | Markdownの静的サイト生成 |
| データストア   | プロセスメモリ         | タスクの一時保持         |

フロントエンドとバックエンドは独立したアプリケーションとして動作します。

## ローカルURL

| 用途           | URL                     |
| -------------- | ----------------------- |
| フロントエンド | `http://127.0.0.1:5173` |
| バックエンド   | `http://127.0.0.1:8787` |
| 仕様書         | `http://127.0.0.1:4174` |

フロントエンドのAPI接続先は`VITE_API_BASE_URL`で上書きできます。未指定時は`http://127.0.0.1:8787/api`を使用します。

## コマンド

```bash
vp install
vp run dev:all
vp run docs:dev
vp run build:all
vp check
vp test
```

`dev:all`はフロントエンドとバックエンド、`docs:dev`は仕様書サイトを起動します。`build:all`はすべてのワークスペース成果物を生成します。

## データ保持

タスクはバックエンドプロセスのメモリに保持します。プロセスを再起動すると初期データへ戻ります。同時更新の競合制御、バックアップ、復元は提供しません。

## レスポンシブ表示

- 1024px以下ではチャート領域を一列へ再配置する。
- 767px以下では登録フォームと一覧を一列にし、ヘッダーと余白を縮小する。
- 540px以下ではタブ、ツールバー、タスク操作、詳細項目を小画面向けに再配置する。
- 動きを減らすOS設定ではアニメーションとトランジションを最小化する。

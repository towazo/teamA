## 受入シナリオ

| ID    | 操作                                        | 合格条件                                         |
| ----- | ------------------------------------------- | ------------------------------------------------ |
| AC-01 | 一覧画面を開く                              | APIのTodoが一覧に表示される                      |
| AC-02 | タスク名、担当者名、状態を指定する          | 指定条件をすべて満たすTodoだけが表示される       |
| AC-03 | 有効な値を入力して登録する                  | 生成したTodoが一覧の先頭に表示される             |
| AC-04 | 完了状態またはタスク名を変更する            | APIと画面の両方が更新後の値になる                |
| AC-05 | 削除確認を承認する                          | APIから削除され、画面からも除かれる              |
| AC-06 | 一覧のタスク名を選ぶ                        | 対応する詳細URLとTodoが表示される                |
| AC-07 | ガント表示を選ぶ                            | 全Todoが開始日から期限までのバーとして表示される |
| AC-08 | バーンダウン表示を選ぶ                      | 完了日を反映した今日までの実績残数が表示される   |
| AC-09 | 完了状態や期限が異なるデータを取得する      | 全Todoを基準に四つの指標が算出される             |
| AC-10 | 読み込み、0件、API失敗、未知のURLを再現する | 状態ごとに定義された案内が表示される             |

## API契約

- [APIエンドポイント](../api/endpoints.md)に定義したメソッド、パス、HTTP状態を満たすこと。
- 成功応答とエラー応答が[API共通規約](../api/conventions.md)の形式に一致すること。
- 登録と更新で[タスクモデル](../domain/todo.md)の入力制約と不変条件を適用すること。

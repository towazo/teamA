# 表示・集計ルール

すべての日付比較で使用する「今日」は、日本標準時の暦日とします。

## 検索と絞り込み

- キーワードの前後空白を除き、大文字と小文字を区別しない。
- タスク名または担当者名の一部にキーワードが含まれるタスクを表示する。
- キーワードが空の場合は、キーワードによる絞り込みを行わない。
- 状態が「すべて」の場合は全件、「未完了」の場合は`isCompleted = false`、「完了」の場合は`isCompleted = true`を表示する。
- キーワードと状態を両方指定した場合は、両方を満たすタスクを表示する。

## サマリー

| 指標     | 算出方法                                                   |
| -------- | ---------------------------------------------------------- |
| 進捗     | `完了件数 ÷ 全件数 × 100`を整数へ四捨五入。全件数が0なら0% |
| 残タスク | `全件数 - 完了件数`                                        |
| 期限超過 | 未完了かつ期限が今日より前の件数                           |
| 次の期限 | 未完了タスクの期限を昇順に並べた先頭。対象がなければ`—`    |

サマリーは検索および状態の絞り込みに影響されず、取得済みの全タスクを対象とします。

## ガントチャート

- タスクを開始日の昇順、同日の場合は期限の昇順で並べる。
- 表示範囲は全タスクの最も早い開始日から最も遅い期限までとする。
- 各バーは開始日から期限までを表す。
- 今日が表示範囲内なら今日を示す線を表示する。
- 優先度ごとにバーを識別し、完了タスクには完了表示を付ける。

## バーンダウンチャート

- 期間はガントチャートと同じ表示範囲を使用する。
- 理想残数は、開始時の全件数から終了日の0件まで直線的に減少させる。
- 各日の実績残数は`全件数 - その日までに完了した件数`とする。
- 「その日までに完了」は`completedAt`が対象日以前のタスクを指す。
- 実績は今日まで表示し、未来日は表示しない。
- 現在の残数が今日の理想残数以下なら「計画内」、上回る場合は差分件数を表示する。

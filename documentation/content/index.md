# Taskly システム仕様書

Tasklyは、個人または小規模チームが日々のタスクと進捗を管理するWebアプリケーションです。本書は、プロダクトが提供する振る舞いと外部契約を定義します。

## 文書構成

| 分類       | 文書                                        | 定義対象                 |
| ---------- | ------------------------------------------- | ------------------------ |
| プロダクト | [プロダクト概要](./product/overview.md)     | 目的、利用者、機能範囲   |
| ドメイン   | [タスクモデル](./domain/todo.md)            | 属性、値集合、不変条件   |
| ルール     | [表示・集計ルール](./rules/presentation.md) | 検索、集計、チャート計算 |
| 画面       | [画面遷移](./ui/navigation.md)              | URLと遷移先              |
| 画面       | [タスク一覧](./ui/task-list.md)             | 一覧画面の操作と状態     |
| 画面       | [タスク詳細](./ui/task-detail.md)           | 詳細画面の表示と状態     |
| API        | [API共通規約](./api/conventions.md)         | 通信、応答、エラー形式   |
| API        | [APIエンドポイント](./api/endpoints.md)     | 各操作の入出力           |
| 運用       | [実行環境](./operations/runtime.md)         | 構成、起動、データ保持   |
| 検証       | [受入条件](./verification/acceptance.md)    | 要件と検証項目の対応     |

## 規範性

属性と入力制約はタスクモデル、計算方法は表示・集計ルール、通信形式はAPI文書を正とします。画面仕様はこれらを参照し、同じ定義を重複して保持しません。
